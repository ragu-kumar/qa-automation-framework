# \# QA Automation Framework (Selenium + TestNG)

# 

# \## Overview

# This project demonstrates a scalable QA automation framework using Selenium WebDriver, TestNG, and Page Object Model (POM).

# 

# \## Key Features

# \- Page Object Model (POM) design

# \- Thread-safe DriverFactory (parallel execution ready)

# \- Config-driven setup using properties file

# \- Retry mechanism for flaky tests

# \- Parallel execution using TestNG

# 

# \## Tech Stack

# \- Java

# \- Selenium WebDriver

# \- TestNG

# \- Maven

# 

# \## Project Structure

# \- src/main/java → framework components (base, pages, utils)

# \- src/test/java → test classes

# \- src/resources → configuration files

# 

# \## How to Run

# Use testng.xml to execute tests.
